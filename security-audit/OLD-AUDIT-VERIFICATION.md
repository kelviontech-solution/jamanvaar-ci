# Disposition of the previous (deleted) audit's 47 claims

The `security-audit/` folder previously contained a report from a different, third-party AI tool (per its own text, likely "Antigravity" or similar), written against commit `d89777c` — before several fix commits landed (`d743f44`, `5b1d4f0`, `c6795c8`, `9ddb563`). The user asked whether that report could be trusted; it could not be used as-is. Every one of its 47 findings (F-001–F-047) was independently re-verified against current source (`9ddb563`) as part of this audit, before any of its content was reused. That old report has been deleted; this table is its replacement — a transparent record of what was checked and what was found.

**Verdict key:** **CONFIRMED** = still true at HEAD, evidence re-derived independently · **FIXED** = was true at `d89777c`, a later commit closed it · **FALSE** = the original claim does not hold up (either never true, or the mechanism doesn't work the way it was described) · **OVERSTATED** = a real issue exists but the original severity/scope was inflated.

## Summary

Of 47 original claims: **2 fully FIXED** since the old report was written (F-027, F-042), **3 FALSE as live exploits** (F-023, F-029, F-032 — each has a real underlying code issue but no reachable attack path), **1 factually wrong sub-claim** (part of F-033), **1 header-injection sub-claim FALSE** (part of F-038), and the remaining **40 CONFIRMED** to varying degrees — several with corrected scope, narrower precondition, or lower severity than originally stated, and two (F-004, F-015) found to be **more severe** than the old report described once their downstream consequences were traced.
